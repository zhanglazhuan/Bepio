# 量产审查（2026-11-01）

当前 `./build.ps1` 是开发固件，**不能用于量产烧录**。`python tools/check_production.py --config sdkconfig --partitions partitions.csv --image build/Bepio.bin` 当前按预期返回失败。启用 `CONFIG_BEPIO_PRODUCTION_BUILD` 后，CMake 配置阶段也会执行同一检查。发布门槛必须在真实实现、密钥配置和硬件验证完成后通过，不能靠改检查结果放行。

## 分区迁移

`partitions.production.csv` 是新设备的候选方案：保留 3 MiB factory 和 3 MiB `voice_data`，增加两个 3 MiB OTA 槽、加密的 `nvs_keys`，并将 Storage 移到 `0xc13000`、缩为 `0x3ed000`。**不要直接把现有设备切到此表**：旧 Storage 位于 `0x610000`，正好与新 `ota_0` 重叠。必须先导出并校验消息与 NVS 数据，或对全新设备执行生产烧录。生产配置还需开启 secure boot、Flash encryption、NVS encryption 和 bootloader 回滚；签名/加密密钥只在受控构建环境中配置。当前 SPIFFS 驱动拒绝加密分区，消息存储需要迁移至受保护的实现才能解除量产门禁。

## 出厂验证记录

每台设备至少记录：eFuse MAC/序列号、板卡批次、固件版本和镜像哈希、Flash 容量、复位原因、最小空闲堆和任务栈水位、屏幕/触摸、ES8311 播放与麦克风采集、MN316 AT/入网、Wi-Fi 连接、实际消息往返、待机与播放电流、OTA 断电回滚。当前没有真实消息/OTA/休眠能力，因此这些项目不能签为通过。
